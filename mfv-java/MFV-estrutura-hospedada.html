Entrada

Workbook de manutenção, abas operacionais, importação versionada e dados de SAP/IW38/IP24.

Domínio

Regras de PCM, periodicidades, mapa anual de 52 semanas, tolerância, capacidade e regras de alocação.

Persistência

JPA com H2 por padrão e PostgreSQL disponível para ambiente externo.

Execução

Spring Boot expõe endpoints REST para saúde, base, mapa PCM e reconciliação SAP.

3. Núcleo PCM

Mapa anual

S01–S52, com visão semanal e base para programação anual.

Periodicidades

1S, 2S, 5S, 13S, 26S, 1A.

Regras de área

AMV 01–04: segunda; AMV 05–08: terça; AMV 09/10/11/13: quarta; Trechos/Lastros/IC: quinta/sexta.

Capacidade

Regra operacional prevista de até 4 ordens/dia, com exceções controladas de até 6 para combinações permitidas de 2S/5S com semanais.

4. Persistência e importação

  • BaseRow: armazena linhas normalizadas por aba.
  • BaseVersion: registra versão e metadados da importação.
  • WorkbookImportService: entrada XLSX via multipart e processamento com Apache POI.
  • BaseQueryService: resumo da base e versão mais recente.
  • SapReconciliationService: reconciliação entre IW38 e IP24.
Princípio de integridade: indicadores operacionais devem ser calculados a partir da base importada; não devem ser inventados como números fixos no front-end.

6. API REST atual

GET /api/health

Verificação de saúde da aplicação.

GET /api/base

Resumo da base persistida e versão mais recente.

POST /api/base/import

Importação de workbook XLSX via multipart.

GET /api/pcm/mapa-52-semanas?year=2026

Mapa anual do PCM por semana ISO.

GET /api/sap/reconciliacao

Comparação entre ordens identificadas em IW38 e IP24.

7. Execução externa

cd IDEAL-MASH/mfv-java
mvn -B clean verify
mvn spring-boot:run

Depois, acessar http://localhost:8080/api/health e os demais endpoints acima.

8. Docker

cd IDEAL-MASH/mfv-java
docker compose up --build

Porta da aplicação: 8080.
